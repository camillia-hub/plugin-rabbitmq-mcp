# RabbitMQ MCP

Inspects and publishes to RabbitMQ. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/rabbitmq-mcp

Installs from the Camillia hub as `rabbitmq-mcp-ea7664`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
